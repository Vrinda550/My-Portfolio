# 🌐 My Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my skills, projects, and introduction as a Computer Science student interested in web development and technology.


## 📌 About the Project

This portfolio website is designed to introduce myself, highlight my technical skills, display my projects, and provide a way for visitors to contact me.

I created this project to practise my HTML and CSS skills and improve my frontend development knowledge through hands-on learning.

## ✨ Features

- **Home Section:** A welcoming introduction with navigation buttons.
- **About Me:** A short introduction about my background and interests.
- **Skills Section:** Displays my technical skills.
- **Projects Section:** Showcases my academic and personal projects.
- **Contact Section:** Includes a contact form for visitors.
- **Responsive Layout:** Designed to adapt to different screen sizes.

## 🛠️ Technologies Used

- HTML5 – For webpage structure and content.
- CSS3 – For styling, layouts, colours, and responsive design.

## 📂 Project Structure

```text
My-Portfolio/
```

## 🚀 How to Run the Project

1. Clone this repository:
   `git clone https://github.com/Vrinda550/My-Portfolio.git`
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
